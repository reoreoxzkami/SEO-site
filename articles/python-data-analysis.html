pandasとは

pandasは、Pythonでデータ分析を行うための最もポピュラーなライブラリです。表形式のデータ（CSV、Excel、SQLクエリ結果など）を効率的に操作・分析するための豊富な機能を提供します。

データサイエンス、機械学習、ビジネス分析など、幅広い分野で標準的に使われており、NumPyと並んでPythonデータ分析の基礎となっています。

インストール

pip install pandas matplotlib

matplotlibはデータの可視化に使います。後ほど使うので一緒にインストールしておきましょう。

データの読み込み

CSVファイルの読み込みは、pandasでは1行でできます。

import pandas as pd

# CSVを読み込む
df = pd.read_csv('sales_data.csv')

# 最初の5行を表示
print(df.head())

#     date     product  price  quantity
# 0  2026-01-01  Apple    120         5
# 1  2026-01-01  Banana    80        10
# 2  2026-01-02  Apple    120         3
# 3  2026-01-02  Orange   150         7
# 4  2026-01-03  Banana    80         8

Excelファイルも同様に読み込めます：

df = pd.read_excel('sales_data.xlsx', sheet_name='Sheet1')

データの確認

読み込んだデータの全体像を把握するための基本操作です：

# データの形状（行数、列数）
print(df.shape)          # (1000, 4)

# データ型の確認
print(df.dtypes)
# date        object
# product     object
# price        int64
# quantity     int64

# 基本統計量
print(df.describe())
#            price    quantity
# count  1000.00000  1000.00000
# mean    116.80000     6.54000
# std      35.20000     3.21000
# min      80.00000     1.00000
# max     150.00000    20.00000

# 欠損値の確認
print(df.isnull().sum())

データのフィルタリング

条件を使ってデータを絞り込む方法です：

# 価格が100以上の行
expensive = df[df['price'] >= 100]

# 複数条件（AND）
apple_high = df[(df['product'] == 'Apple') & (df['price'] >= 120)]

# 複数条件（OR）
citrus = df[df['product'].isin(['Orange', 'Apple'])]

# 文字列を含む行
apple_items = df[df['product'].str.contains('Apple', case=False)]

データの集計

グループ化と集計は、データ分析の中核となる操作です：

# 商品ごとの売上合計
sales_by_product = df.groupby('product')['price'].sum()
# product
# Apple     36000
# Banana    16000
# Orange    45000

# 商品ごとの平均単価と数量
summary = df.groupby('product').agg({
    'price': 'mean',
    'quantity': ['sum', 'mean']
})

# 日付ごとの売上
daily_sales = df.groupby('date')['price'].sum().sort_values(ascending=False)
groupby + aggの組み合わせを覚えれば、大部分の集計処理はカバーできます。

データの可視化

pandasはmatplotlibと連携して、簡単にグラフを描けます：

import matplotlib.pyplot as plt

# 折れ線グラフ
df.groupby('date')['price'].sum().plot(kind='line', figsize=(10, 5))
plt.title('日別売上')
plt.show()

# 棒グラフ
df.groupby('product')['quantity'].sum().plot(kind='bar')
plt.title('商品別売上数量')
plt.show()

# ヒストグラム
df['price'].plot(kind='hist', bins=20)
plt.title('価格の分布')
plt.show()

実践的なTips

  1. astype で型変換：df['price'] = df['price'].astype(float)
  2. apply で列に一括処理：df['total'] = df.apply(lambda r: r['price'] * r['quantity'], axis=1)
  3. merge で表を結合：pd.merge(df1, df2, on='product')
  4. pivot_table：pd.pivot_table(df, values='price', index='date', columns='product', aggfunc='sum')
  5. to_csv で保存：df.to_csv('output.csv', index=False)

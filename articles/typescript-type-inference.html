型推論とは

TypeScriptの型推論（Type Inference）とは、明示的に型を書かなくても、TypeScriptがコードの文脈から自動的に型を判断してくれる機能です。これにより、開発者は型安全性を保ちながら、冗長な型注釈を省略できます。

TypeScriptの型推論は、賢い言語設計のおかげで「書かなくていい型」を大幅に減らしてくれます。しかし、「書くべき型」を見極めることが重要です。

基本的な型推論

変数を初期化すると、その値から型が推論されます：

// 変数の初期化から推論
let name = "Alice";      // string型
let age = 25;            // number型
let isActive = true;     // boolean型
let items = [1, 2, 3];   // number[]型

// 関数の戻り値も推論される
function add(a: number, b: number) {
  return a + b;          // 戻り値はnumber型と推論
}

// 関数式の戻り値も推論
const multiply = (a: number, b: number) => a * b;  // numberを返す

コンテキストベースの型推論

式が使われる文脈から型が推論されることもあります。これを「コンテキストベースの型推論」と呼びます：

// イベントハンドラーの型は自動的に推論
button.addEventListener('click', (event) => {
  // event は MouseEvent と推論される
  console.log(event.clientX);
});

// Window.onkeydown の文脈から KeyboardEvent が推論
window.onkeydown = (event) => {
  console.log(event.key);
};

これは、DOM APIの型定義が文脈を提供しているため、引数の型を書かなくても正しく推論される例です。

最善共通型

配列に複数の型が混在する場合、TypeScriptは「最善共通型（Best Common Type）」を推論します：

// numberとstringの混合 → (string | number)[]
let mixed = [1, "two", 3];
// (string | number)[]型

// 全てnumber → number[]
let nums = [1, 2, 3];
// number[]型

// クラスの継承関係がある場合
class Animal { name: string; }
class Dog extends Animal { bark() {} }
class Cat extends Animal { meow() {} }

let pets = [new Dog(), new Cat()];
// Animal[] と推論（共通の親型）

型注釈が必要な場面

型推論に頼れない、明示的な型注釈が必要なケースを紹介します：

1. 変数を初期化せずに宣言する

// ❌ 型推論できない（anyになる）
let count;
count = 5;       // この時点でany

// ✅ 明示的な型注釈
let count: number;
count = 5;

2. 関数パラメータの型

// ❌ パラメータの型は推論されない
function greet(name) {  // nameはany
  return `Hello, ${name}`;
}

// ✅ 明示的な型注釈
function greet(name: string): string {
  return `Hello, ${name}`;
}

3. 期待する型が推論より広い場合

// 推論では string になるが、string | null にしたい
let userName: string | null = getNameFromAPI();

4. オブジェクトの型を固定したい

// 推論では { name: string } になる
const user = { name: "Alice" };

// より詳細な型を定義したい場合
interface User {
  name: string;
  age?: number;
  email?: string;
}

const user: User = { name: "Alice" };

ジェネリクスと型推論

ジェネリクス関数を呼び出すとき、型引数は引数から自動的に推論されます：

function identity<T>(value: T): T {
  return value;
}

// 型引数を省略しても推論される
const result1 = identity("hello");    // T = string
const result2 = identity(42);        // T = number
const result3 = identity([1, 2, 3]); // T = number[]

// 明示的に指定することも可能
const result4 = identity<string>("hello");

ジェネリクスを使うことで、型推論の恩恵を最大限に受けつつ、型安全性を保てます。

実践的なTips

  1. 推論に任せる：変数の初期化、関数の戻り値、コールバックの引数は推論に任せる
  2. 公開APIには型を書く：関数のパラメータ、エクスポートする変数には明示的に型を書く
  3. noImplicitAny：tsconfig.jsonで"noImplicitAny": trueを設定して、暗黙のanyを防ぐ
  4. typeof で型を再利用：type MyType = typeof existingObject
  5. as const でリテラル型：const status = "active" as const → 型は "active" になる
// as const の活用例
const config = {
  endpoint: "/api/v1",
  method: "GET",
} as const;
// { readonly endpoint: "/api/v1"; readonly method: "GET" }

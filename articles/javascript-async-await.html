async/awaitとは

async/awaitは、JavaScriptの非同期処理をよりシンプルに書くための構文です。Promiseの上に構築されており、非同期処理をまるで同期処理のように直感的に記述できます。

コールバック地獄やPromiseの.then()チェーンのネストに悩まされることなく、読みやすいコードを書くことができます。

Promiseのおさらい

async/awaitを理解するには、まずPromiseを理解する必要があります。Promiseは「将来完了する操作」を表すオブジェクトです。

// Promiseの基本
function fetchUser(id) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (id > 0) {
        resolve({ id, name: 'ユーザー' + id });
      } else {
        reject(new Error('無効なID'));
      }
    }, 1000);
  });
}

// .then()チェーンで処理
fetchUser(1)
  .then(user => {
    console.log(user); // { id: 1, name: 'ユーザー1' }
    return fetchUser(2);
  })
  .then(user2 => {
    console.log(user2);
  })
  .catch(err => {
    console.error(err);
  });

.then()が連鎖するとネストが深くなり、コードの流れが追いづらくなります。これを解決するのがasync/awaitです。

基本的な使い方

asyncキーワードを関数の前に付けると、その関数は自動的にPromiseを返します。その関数内でawaitを使うと、Promiseの解決を待つことができます。

// async/awaitの基本
async function getUsers() {
  try {
    const user1 = await fetchUser(1);
    console.log(user1); // { id: 1, name: 'ユーザー1' }

    const user2 = await fetchUser(2);
    console.log(user2); // { id: 2, name: 'ユーザー2' }

    return [user1, user2];
  } catch (err) {
    console.error('エラー:', err);
  }
}

getUsers().then(users => console.log(users));

awaitがある行で処理が一時停止し、Promiseが解決されたら次の行に進みます。見た目は同期処理とほぼ同じですが、実際には非同期で動作しています。

エラーハンドリング

async/awaitでは、try/catch構文でエラーを処理します。Promiseの.catch()に比べて、より自然なエラー処理が可能です。

async function getUser(id) {
  try {
    const user = await fetchUser(id);
    return user;
  } catch (err) {
    // エラーの種類に応じた処理
    if (err.message === '無効なID') {
      return { id: null, name: 'ゲスト' };
    }
    throw err; // 再スロー
  }
}

並列処理（Promise.all）

複数の非同期処理を順番にawaitすると、1つずつ待つため処理が遅くなります。互いに依存しない処理ならPromise.allで並列実行すべきです。

// ❌ 順番実行（遅い）
async function fetchAllSlow() {
  const user1 = await fetchUser(1); // 1秒待つ
  const user2 = await fetchUser(2); // さらに1秒待つ
  // 合計2秒
  return [user1, user2];
}

// ✅ 並列実行（速い）
async function fetchAllFast() {
  const [user1, user2] = await Promise.all([
    fetchUser(1),
    fetchUser(2)
  ]);
  // 合計1秒（同時に実行）
  return [user1, user2];
}

実践的なパターン

ループ内でのasync/await

// for...ofループ（順次実行）
async function processUsers(ids) {
  for (const id of ids) {
    const user = await fetchUser(id);
    console.log(user);
  }
}

// Promise.all + map（並列実行）
async function processUsersParallel(ids) {
  const users = await Promise.all(
    ids.map(id => fetchUser(id))
  );
  users.forEach(user => console.log(user));
}

API呼び出しの例

async function fetchPosts() {
  try {
    const res = await fetch('https://api.example.com/posts');
    if (!res.ok) {
      throw new Error(`HTTP ${res.status}`);
    }
    const posts = await res.json();
    return posts;
  } catch (err) {
    console.error('取得失敗:', err);
    return [];
  }
}

よくある落とし穴

  • トップレベルでawaitは使えない（ES2022以降はESモジュールで可能だが、基本はasync関数内で使う）
  • forEach内のawaitは効かない：forEachのコールバックは非同期関数でもawaitを待たない。for...ofを使う
  • 忘れられたawait：awaitを付け忘れるとPromiseがそのまま返り、意図しない動作になる
  • 過剰なawait：依存関係のない処理を順番にawaitするとパフォーマンスが落ちる。Promise.allを活用する
// ❌ forEachの罠
ids.forEach(async id => {
  const user = await fetchUser(id); // 待たない！
});

// ✅ for...ofを使う
for (const id of ids) {
  const user = await fetchUser(id); // 正しく待つ
}

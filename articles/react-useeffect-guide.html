useEffectとは何か

ReactのuseEffectは、関数コンポーネント内で副作用（side effect）を扱うためのフックです。副作用とは、コンポーネントのレンダリング結果に直接関係しない処理のことで、具体的には以下のようなものが該当します。

  • APIからのデータ取得
  • DOMの直接操作（ref経由）
  • タイマーの設定・解除
  • イベントリスナーの登録・解除
  • ローカルストレージへの読み書き

クラスコンポーネントにおけるcomponentDidMount、componentDidUpdate、componentWillUnmountを一つにまとめたものと考えるとわかりやすいでしょう。

基本的な使い方

最も基本的な形は、コールバック関数を渡すパターンです。

import { useEffect } from 'react';

function MyComponent() {
  useEffect(() => {
    console.log('コンポーネントがレンダリングされました');
  });

  return <div>Hello</div>;
}

この場合、コンポーネントがレンダリングされるたびに実行されます。通常は、より制御された動作をさせるために依存配列を使います。

// マウント時に1回だけ実行
useEffect(() => {
  fetchData();
}, []);

// countが変化したときだけ実行
useEffect(() => {
  document.title = `カウント: ${count}`;
}, [count]);

クリーンアップ関数

イベントリスナーの登録やタイマーの設定など、後始末が必要な処理ではクリーンアップ関数を返します。これにより、メモリリークを防ぐことができます。

useEffect(() => {
  const timer = setInterval(() => {
    console.log('tick');
  }, 1000);

  // クリーンアップ関数
  return () => {
    clearInterval(timer);
    console.log('タイマーをクリアしました');
  };
}, []);
クリーンアップ関数は、コンポーネントがアンマウントされるときと、次回のeffectが実行される前の両方で呼ばれます。

依存配列の理解

依存配列はuseEffectの最も重要な概念の一つです。配列に指定した値が変更されたときのみ、effectが再実行されます。

依存配列実行タイミング
指定なし毎レンダリング後
[]マウント時1回のみ
[value]マウント時 + value変更時
[a, b]マウント時 + aまたはb変更時

無限ループを防ぐ

useEffectで最もよくある落とし穴が無限ループです。状態を更新する処理を依存配列なしで実行すると、無限にレンダリングが繰り返されます。

// ❌ 無限ループになる
useEffect(() => {
  setCount(count + 1);
}); // 依存配列なし → 毎レンダリング実行 → setCount → 再レンダリング → また実行...

// ✅ 正しい方法
useEffect(() => {
  setCount(prev => prev + 1);
}, [trigger]); // triggerが変わったときだけ実行

無限ループを防ぐポイント：

  1. 状態の更新には関数型アップデートを使う（setCount(prev => ...)）
  2. 依存配列を正しく指定する
  3. effect内で不要な状態更新を避ける

カスタムフックへの抽出

useEffectのロジックが複雑になったら、カスタムフックに抽出することで、再利用性と可読性が向上します。

function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    const handleResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);

  return width;
}

// 使い方
function MyComponent() {
  const width = useWindowWidth();
  return <p>ウィンドウ幅: {width}px</p>;
}

ベストプラクティス

  • React Hooks ESLintプラグイン（eslint-plugin-react-hooks）を使い、依存配列の漏れを検出する
  • effect内で非同期処理を行うときは、async/awaitを直接使わず、別の関数として定義する
  • 複数の副作用は、別々のuseEffectに分ける
  • クリーンアップが必要な処理は必ずクリーンアップ関数を返す
// 非同期処理の正しい書き方
useEffect(() => {
  let isMounted = true;

  const fetchData = async () => {
    const res = await fetch('/api/data');
    if (isMounted) {
      setData(await res.json());
    }
  };

  fetchData();
  return () => { isMounted = false; };
}, []);

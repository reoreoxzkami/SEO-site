FlexboxとGridの違い

CSSでレイアウトを作るための2つの強力な仕組みが「Flexbox」と「Grid」です。どちらもモダンブラウザで完全にサポートされていますが、設計思想が異なります。

一言で言えば：Flexboxは1次元（横または縦のどちらか）のレイアウト、Gridは2次元（縦横同時）のレイアウトに向いています。

項目FlexboxGrid
次元1次元2次元
向き行または列のどちらか行と列を同時に
適している用途ナビ、ボタン群、カード1行ページ全体、ギャラリー、複雑な配置
アイテムサイズコンテンツに依存コンテナが制御

Flexboxの基本

Flexboxは、アイテムを行または列に並べるためのレイアウトシステムです。コンテナにdisplay: flexを指定するだけで使えます。

/* 基本的なFlexbox */
.container {
  display: flex;
  gap: 16px;
}

/* 横並び → 縦並びに変更 */
.container-vertical {
  display: flex;
  flex-direction: column;
}

/* 中央揃え */
.center {
  display: flex;
  justify-content: center; /* 主軸方向 */
  align-items: center;     /* 交差軸方向 */
  min-height: 100vh;
}

/* 間隔を均等に */
.between {
  display: flex;
  justify-content: space-between;
}

主要なFlexプロパティ

  • flex-direction：row（横）/ column（縦）/ row-reverse / column-reverse
  • justify-content：主軸方向の配置（flex-start, center, space-between, space-around）
  • align-items：交差軸方向の配置（stretch, center, flex-start, flex-end）
  • flex-wrap：折り返し（nowrap, wrap）
  • flex-grow / flex-shrink / flex-basis：アイテムの伸縮
/* アイテムの比率を指定 */
.sidebar { flex: 1; }    /* 1倍 */
.main    { flex: 3; }    /* 3倍 */
.aside   { flex: 1; }    /* 1倍 */
/* → サイドバー:メイン:サイド = 1:3:1 */

Gridの基本

Gridは、行と列の両方を同時に制御できる2次元レイアウトシステムです。ページ全体のレイアウトや、複雑な配置に向いています。

/* 基本的なGrid */
.grid-container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  gap: 16px;
  min-height: 100vh;
}

/* ヘッダー・フッター・サイドバーの配置 */
.header  { grid-column: 1 / -1; }
.sidebar { grid-column: 1; grid-row: 2; }
.main    { grid-column: 2; grid-row: 2; }
.aside   { grid-column: 3; grid-row: 2; }
.footer  { grid-column: 1 / -1; }

主要なGridプロパティ

  • grid-template-columns：列の幅を指定（fr単位、px、auto、minmax）
  • grid-template-rows：行の高さを指定
  • grid-column / grid-row：アイテムの配置位置
  • gap：行・列の間隔
  • repeat()：繰り返しパターンの簡略記法
/* repeat()で簡潔に */
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* minmaxで最小・最大幅を指定 */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 16px;
}

どちらを使うべきか

迷ったときの判断基準：

  • Flexboxを使う：ナビゲーションバー、ボタンの並び、1行のカード、ツールバー、フォーム項目の横並び
  • Gridを使う：ページ全体のレイアウト、画像ギャラリー、複数行のカード配置、複雑な配置パターン
  • 併用が最適なケースも多い：外側をGrid、内側をFlexboxにするなど
「1次元ならFlexbox、2次元ならGrid」と覚えておけば、まず間違いありません。実際のプロジェクトでは両方を組み合わせて使うのが一般的です。

実践的なレイアウトパターン

カードレイアウト（Grid）

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}

センタリング（Flexbox）

/* 上下左右中央揃え - Flexbox版 */
.center-flex {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 上下左右中央揃え - Grid版（1行でOK） */
.center-grid {
  display: grid;
  place-items: center;
}

聖杯レイアウト（Grid）

.holy-grail {
  display: grid;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

.hg-header { grid-area: header; }
.hg-nav    { grid-area: nav; }
.hg-main   { grid-area: main; }
.hg-aside  { grid-area: aside; }
.hg-footer { grid-area: footer; }

レスポンシブ対応

FlexboxとGridを組み合わせれば、メディアクエリなしでもある程度のレスポンシブ対応が可能です。

/* auto-fill + minmaxで自動折り返し */
.responsive-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(min(100%, 250px), 1fr));
  gap: 16px;
}

/* メディアクエリで列数を変更 */
@media (max-width: 768px) {
  .card-grid {
    grid-template-columns: 1fr;
  }
  
  .holy-grail {
    grid-template-areas:
      "header"
      "main"
      "nav"
      "aside"
      "footer";
    grid-template-columns: 1fr;
  }
}

min(100%, 250px)を使うことで、画面幅が250px未満の場合でもカラムがはみ出さないようにできます。

よくある落とし穴

  • Flexboxで折り返し忘れ：flex-wrap: wrapを指定しないと、アイテムが縮んで1行に収まってしまう
  • Gridのfr单位の誤解：frは「残り空間の割合」であって、「全体の割合」ではない。最小幅はminmax()で指定する
  • gapのブラウザ対応：Flexboxのgapはモダンブラウザで対応済みだが、古いブラウザでは使えない（marginで代替）
  • Gridの暗黙のトラック：grid-template-rowsにない行は暗黙的に作られる。明示的に指定する方が安全
  • 両方使う順序：外側をGrid、内側をFlexboxにするのが基本。逆にすると意図しない崩れが起きることがある
/* ❌ gap未対応ブラウザ向けのフォールバック */
.legacy-support > * {
  margin-right: 16px;
}
.legacy-support > *:last-child {
  margin-right: 0;
}

/* ✅ モダンブラウザならgapがシンプル */
.modern {
  display: flex;
  gap: 16px;
}
